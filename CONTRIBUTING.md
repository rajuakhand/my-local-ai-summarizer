# Contributing to AI StudySuite Pro

First off, thanks for taking the time to contribute! ❤️

## How Can You Contribute?

### Reporting Bugs
- Check if the bug has already been reported in [Issues](https://github.com/rajuakhand/my-local-ai-summarizer/issues)
- If not, create a new issue with a clear title, description, steps to reproduce, and expected behavior

### Suggesting Features
- Open an issue with the title `Feature Request: [Name]`
- Explain the feature, why it's useful, and how it should work

### Pull Requests
1. Fork the repository
2. Create your feature branch (`git checkout -b feature/AmazingFeature`)
3. Commit your changes (`git commit -m 'Add some AmazingFeature'`)
4. Push to the branch (`git push origin feature/AmazingFeature`)
5. Open a Pull Request

## Code Guidelines
- Keep code clean and readable
- Follow existing code style
- Test your changes locally with `streamlit run app.py`
- Don't commit API keys or secrets

## Questions?
Feel free to open an issue for any questions or suggestions.

Thanks for helping make AI StudySuite Pro better!
